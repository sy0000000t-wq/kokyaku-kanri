# Google 側の設定手順

顧客管理ツールが、あなたの Google ドライブにデータファイルを読み書きするための設定です。
**一度やれば、以後は不要です。** 10分ほどで終わります。

作業するのは <https://console.cloud.google.com/> です。ご自身の Google アカウントで入ってください。

---

## 0. 前提：何を許可することになるのか

このアプリが要求する権限は **`drive.file`** の1つだけです。

- できること：**このアプリが作ったファイル**の読み書き
- できないこと：ドライブにある**他のファイルを見ること**

写真も、仕様書も、他のフォルダも、アプリからは一切見えません。
Google の分類でも「非センシティブ」に区分される、いちばん狭い権限です。

---

## 1. プロジェクトを作る

1. <https://console.cloud.google.com/> を開く
2. 画面上部のプロジェクト選択（「プロジェクトを選択」）をクリック
3. 右上の **「新しいプロジェクト」**
4. プロジェクト名に `顧客管理ツール` と入力して **「作成」**
5. 作成後、上部のプロジェクト選択が `顧客管理ツール` になっていることを確認

---

## 2. Drive API を有効にする

1. 左のメニューから **「API とサービス」→「ライブラリ」**
2. 検索欄に `Google Drive API` と入力
3. 出てきた **Google Drive API** をクリック
4. **「有効にする」**

---

## 3. 同意画面を作る

アプリが権限を求めるときに出る画面の設定です。

1. 左のメニューから **「API とサービス」→「OAuth 同意画面」**
2. User Type は **「外部」** を選んで「作成」
   - 組織アカウントでない個人の Google アカウントでは、これしか選べません
3. 入力するのは次の3つだけです
   - **アプリ名**：`顧客管理ツール`
   - **ユーザーサポートメール**：ご自身のメールアドレス
   - **デベロッパーの連絡先情報**：同じメールアドレス
4. 「保存して次へ」
5. **スコープ**の画面 → 何も追加せず「保存して次へ」
   - スコープはアプリ側から指定するので、ここでの登録は不要です
6. **テストユーザー**の画面 → 何も追加せず「保存して次へ」
7. 「ダッシュボードに戻る」

### 3-2. 公開ステータスを「本番」にする（重要）

同意画面のページに **「公開ステータス」** という欄があります。

- 「テスト中」のままだと、**7日ごとに再ログインが必要**になります
- **「アプリを公開」** を押して「本番環境」にしてください
- `drive.file` は非センシティブな権限なので、**Google の審査は不要**です
  （審査が必要という警告が出た場合は、要求している権限が広すぎるので教えてください）

---

## 4. OAuth クライアント ID を作る

1. 左のメニューから **「API とサービス」→「認証情報」**
2. 上部の **「＋ 認証情報を作成」→「OAuth クライアント ID」**
3. アプリケーションの種類：**「ウェブ アプリケーション」**
4. 名前：`顧客管理ツール`
5. **「承認済みの JavaScript 生成元」** に、次の2つを「＋ URI を追加」で登録します

```
http://localhost:3100
https://sy0000000t-wq.github.io
```

- 上は Mac で動かして確認するとき用（配って使うだけなら不要）
- 下は公開サイトを開くとき用。**これは必ず登録してください**
- **末尾にスラッシュや、その先のパスは付けないでください**

6. 「承認済みのリダイレクト URI」は **空のままで構いません**
   （このアプリはリダイレクトを使わない方式で認証します）
7. **「作成」**

---

## 5. クライアント ID を控える

作成すると、次のような文字列が表示されます。

```
123456789012-abcdefghijklmnopqrstuvwxyz123456.apps.googleusercontent.com
```

これを**そのままコピー**します。

- これは**公開して問題のない値**です（ブラウザのJavaScriptに埋め込まれる前提の識別子）
- **「クライアントシークレット」のほうは使いません。** どこかに書く必要もありません

---

## 6. アプリに貼る

1. 顧客管理ツールを開く
2. **設定 → データ管理**
3. **「Google への接続口（この端末）」** の欄に、控えたクライアントIDを貼る
4. **「この端末で使う」** を押す（自動で開き直します）
5. **ドライブに接続する** を押してサインイン

「いま使っているのは**自分の接続口**です」と出ていれば完了です。

端末ごとの設定なので、**PC とスマホでそれぞれ**貼ってください。
同じクライアントIDを使い回して構いません。

---

## 配布元と切り離す意味

接続口を自分のものにすると、Google との通信は**自分の Google Cloud の枠だけ**を通ります。
配布元のプロジェクトには一切かかりません。データはもともと各自のドライブに入るので、
接続口を差し替えれば完全に独立して使えます。

空のままでも動きますが、その場合は配布元の接続口を借りている状態です。

---

## つまずいたときは

| 症状 | 対処 |
|---|---|
| 「このアプリは確認されていません」と出る | 公開ステータスが「テスト中」のままです。手順 3-2 を実施 |
| ログインしても弾かれる | JavaScript 生成元の URL を確認。末尾スラッシュが付いていないか |
| 審査が必要と表示される | 権限が広すぎます。そのまま進めず連絡してください |
| 7日ごとにログインを求められる | 公開ステータスが「テスト中」です。手順 3-2 を実施 |
| 貼ったのに「配布元の接続口」のまま | 「この端末で使う」を押し忘れ。押すと自動で開き直します |
